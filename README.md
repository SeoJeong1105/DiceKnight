# [Unity 3D] DiceKnight

## 1. 프로젝트 소개
* <킹덤컴: 딜리버런스>에 나오는 주사위 게임 "Farkle"을 Unity 3D 모바일 게임으로 구현했습니다. 
* 6개의 주사위를 굴려 특정 조합으로 점수를 획득해 먼저 목표 점수에 도달한 사람이 이기게 됩니다.

* Unity
* C#
* JSON
